# Progiwell

> Pronounced **pro-jee-well** (`/ˈproʊ.dʒi.wɛl/`, soft "g" as in Italian *Luigi*) — an independent lab building lightweight, privacy-first open-source utilities and self-hosted tools.

---

## Featured Tools

| Project | License | Description |
| :--- | :--- | :--- |
| **[Debrid Hub](https://github.com/progiwell/debrid-hub)** | `GPL-3.0` | Ultra-lightweight (<50 MB RAM) Debrid download daemon (FastAPI + Aria2c + Unrar/7-Zip) paired with a Chrome & Firefox MV3 extension and qBittorrent API emulation for `*arr` stacks. |
| **[Gemini PR Reviewer](https://github.com/progiwell/gemini-pr-reviewer)** | `MIT` | Multi-provider automated AI pull request code review GitHub Action (Google Gemini, Groq, OpenRouter, Cerebras, Mistral) with strict original-issue verification and inline diff comments. |

---

## Design Principles

- **100% Open Source:** Auditable repositories published under standard OSI-approved licenses (`GPL-3.0` / `MIT`) so you can inspect every line running on your hardware.
- **Local-First Privacy:** Zero telemetry, zero tracking pixels, and zero third-party relay servers. Credentials stay on your own device.
- **Minimal Footprint:** Focused, lean tools built for NAS devices, single-board computers, and fast CI runners.
