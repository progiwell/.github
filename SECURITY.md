# Security Policy

## Reporting a Vulnerability

Please do **not** open public GitHub issues for security vulnerabilities.

- **Preferred:** Use **GitHub Private Vulnerability Reporting** (**Security → Advisories → Report a vulnerability**) on the affected repository.
- **Email fallback:** Send a report to **[support@progiwell.com](mailto:support@progiwell.com)** including:
  - Repository name and affected version or commit SHA
  - Clear steps to reproduce the issue
  - Potential impact and any suggested remediation

## Response Commitment

We aim to acknowledge security reports on a best-effort basis within **7 days** and coordinate public disclosure after a fix is tested and released.
